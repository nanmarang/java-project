# Personal Expense Tracker

A console-based Java project for tracking expenses with basic reporting and search features.

## Project Structure

- `src/`
- `main/Main.java`
- `models/Expense.java`
- `models/Income.java`
- `models/User.java`
- `models/Category.java`
- `models/ExpenseRecord.java`
- `manager/ExpenseManager.java`
- `manager/SearchManager.java`
- `reports/Report.java`
- `reports/ExpenseReport.java`
- `interfaces/Printable.java`
- `interfaces/Searchable.java`
- `interfaces/AdvancedSearch.java`
- `utils/Validator.java`
- `utils/Constants.java`
- `utils/DateUtil.java`
- `utils/FileManager.java`
- `utils/VirtualThreadDemo.java`
- `data/expenses.txt`

## Features

- Add, view, update, delete expenses
- Search by title and category
- Generate expense report
- Show total and category-wise expenses
- Supports Java OOP concepts like inheritance, interfaces, abstract classes, records, and cloning
- Includes Java 21 virtual thread demo example

## Running

Compile and run from the project root:

```bash
javac main/Main.java
java main.Main
```
